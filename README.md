# Bool calculator
## What problem it solves?
* Makes truth table
* Makes CCNF and CDNF form of your expression
* Print your expression in {|&!}, {/}, {%}, {&^1} basises
## Syntax
* & - and
* | - or
* ! - not
* = - equals
* ^ - xor (doesnot equals)
* \> (<) - impication
* / - nand (not and)
* % - nor (not or)
## How to use
Go to directory where this program is
```sh
./bool_calculator <path to file>
```
Print your expression into file and give its path as argument to program in start
## Notice
Maximum length of expression is 4095 symbols
